# `data/`

Scratch directory for sample inputs/outputs used during local development.

Do **not** commit large binaries (photos, generated PNGs, model artifacts) here.
Keep this directory tracked with only this note; everything else is ignored via
the backend `.gitignore`.

Suggested local layout (git-ignored):

```
data/
  samples/      # a few small example room photos for manual testing
  outputs/      # generated staged images from manual runs
```
